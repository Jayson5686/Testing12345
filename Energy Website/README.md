# Energy Data Website

This project is an energy data website created using HTML, CSS
and JavaScript.

## Project Structure

energy-webpage-v1/

- css/
  - styles.css

- data/
  - data.csv

- images/
  - PowerIcon.png

- js/
  - scripts.js

- index.html
- README.md

## Dataset

The website uses the CSV dataset stored in:

data/data.csv

The dataset contains energy production values for:

- Solar
- Wind
- Hydro
- Natural Gas

for the years 2020 to 2024.

## Features

The website includes:

- Energy production overview
- Production statistics
- Energy source percentages
- Energy production chart
- Dataset table

The values displayed on the website are calculated directly
from the CSV dataset.

## Technologies

- HTML
- CSS
- JavaScript
- CSV

## How to Run

Open the project in Visual Studio Code.

Use Live Server to open index.html.

The CSV file is loaded by JavaScript from:

data/data.csv
